Home DNS Server

General

Recently, I’ve become interested in how computer networks are built and how they work, so I bought a Raspberry Pi and started setting it up as a local DNS server at home.

Technical details:

I am setting up the server using the open-source Pi-hole software.

Main reasons to host a local DNS server:

  • Network wide ad-blocking
  • Reduced latency because of caching
  • More privacy
