About me

I am Zdenkó Gera, a recent Computer Science graduate currently working as a Service Desk Agent at BT Group. In my freetime, I enjoy programming and experimenting with new technologies. Lately, I have been exploring the capabilities of Raspberry Pi and would also love to try a few concepts using ESP32 or Arduino microcontrollers. One of my long-term goals is to build a Rubik's Cube solver robot - an extension of my bachelor's thesis project, which is a web application designed to teach users how to solve the 3x3x3 and 2x2x2 cubes using the beginner's method.

The purpose of this website is to showcase some of my projects with some documentation and visuals, making them more accessible and engaging than just code repositories with a README on GitHub.
