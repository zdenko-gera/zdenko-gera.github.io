Szobaberles.hu

General

I worked on Szobaberles.hu because of a personal inner motivation. The webapplication was available on the internet for one year. My goal with it was to create a centralized forum for flatshare ads in Hungary.

Technical details:

The server side needs were fulfilled using Laravel and for the frontend operations I used native JavaScript.

Gallery

The gallery was made using the open-source Lightbox script.
